Let your coding agent query your database. Keep the credentials on your machine.

Pluk is a macOS menu bar app that turns Postgres, MySQL, and SQLite into local MCP endpoints. Your agent calls localhost; Pluk applies a per-integration policy and records every tool call in the activity log.

Put a boundary in front of the database.

A raw database credential gives an agent more reach than one query needs. Pluk keeps the broker on your machine and sets the boundary per integration.

Local endpoint

The server listens on localhost. Integrations and credentials live in ~/.pluk/.

Read-only SQL

The SQL policy classifies each statement and blocks writes before they reach Postgres, MySQL, or SQLite.

Activity log

Allowed and blocked calls are recorded locally; new entries appear without a refresh.

One URL, one grant

Each integration gets a bearer URL. Give an agent only the database it needs.

How it works

Connect a database once, then give your coding agent its local MCP URL.

  1. Add your database

    Open Pluk from the menu bar and choose Postgres, MySQL, or SQLite. Fill in its fields, add optional SSH or SSL settings, then run Test.

  2. Copy the local MCP URL

    Each integration gets a unique URL such as http://localhost:4242/mcp/<token>. Give it only to the agent that needs this database.

  3. Add it to your coding agent

    Paste the URL into Codex, opencode, Claude Code, Cursor, Windsurf, or Antigravity. Pluk's detail view provides the client snippet.

  4. Query within the policy

    The agent calls database tools through Pluk. The SQL policy checks each statement, and the activity log records allowed and blocked calls.

One client entry

Connect the databases you already use.

Postgres, MySQL, and SQLite share Pluk's SQL adapter family and 12-tool set. They differ only in how they connect.

  • Postgres

    Network database with optional SSH tunnel and SSL/TLS.

    12 SQL tools

  • MySQL

    Network database with default port 3306, SSH tunnel, and SSL/TLS.

    12 SQL tools

  • SQLite

    Local file database. No network or tunnel.

    12 SQL tools

Also available: Linear, Sentry, SSH, Laravel Herd, Spark Mail, and GitHub CLI use the same pluggable adapter model. A group bundles several integrations behind one URL and namespaces each member's tools.

Install Pluk.

Pluk builds from source on macOS 14 or later. You need Bun, a Swift toolchain, and Make.

  • macOS 14 or later
  • Bun
  • Swift toolchain — Xcode or Command Line Tools
  • Make

make install compiles the server, builds the app, copies Pluk.app to /Applications, and launches it in your menu bar.
