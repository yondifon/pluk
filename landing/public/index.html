Pluk

Open source · Local MCP endpoints

Let your coding agent reach your tools.

Pluk is a macOS menu bar app that turns your databases, Linear, Sentry, and SSH into local MCP endpoints. Your coding agent talks to your real tools — while every credential stays on your machine.

Download for macOS Apple Silicon and Intel · macOS 14 or later

macOS today. Windows and Linux are next. Pluk is open source — read the code on GitHub.

How it works

  1. 01

    Install and launch

    Open the .dmg, drag Pluk to Applications, and launch it. It lives in your menu bar — no dock icon, no window in the way.

  2. 02

    Connect a tool

    Pick a tool — your Postgres database, your Linear workspace, an SSH host — and enter its credentials once. Pluk starts a local MCP endpoint for it on your machine.

  3. 03

    Paste the URL into your agent

    Pluk gives you a localhost URL. Paste it into your coding agent's MCP config. The agent can now reach that tool — through Pluk, on your machine, under your control.

What connects

Every tool gets the same setup: enter credentials once, get a local URL, paste it into your agent.

  • DB

    Postgres

    Query tables, inspect schemas, explore data — your agent reads your database without holding connection strings.

  • DB

    MySQL

    Same interface as Postgres. One tool config, one local endpoint, full read access.

  • DB

    SQLite

    Point it at a .db file. The agent queries it through Pluk — never touches the file directly.

  • MCP

    Linear

    Your agent reads issues, projects, and cycles through Linear's official MCP server. Sign in once, and your token stays on your machine.

  • MCP

    Sentry

    Pull error reports and stack traces into your agent's context through Sentry's official MCP server.

  • SSH

    SSH

    Give your agent access to a remote host over SSH. Keys stay in your keychain, not in your agent config.

Why local matters

Pluk runs entirely on your machine. There is no cloud relay, no account to create, and no data leaving your laptop unless you say so.

  • Credentials

    Your database passwords, API tokens, and SSH keys live on your machine and nowhere else. Pluk connects locally — nothing is sent to a remote server.

  • Read-only by default

    A built-in read-only policy blocks write operations before they leave your machine. Your agent can read your data; it cannot change it unless you choose to allow that.

  • Full audit log

    Every call your agent makes — allowed or blocked — is recorded locally. You can review exactly what was requested and what was returned.

After you download

What do I install?
A single .dmg file. Drag Pluk to your Applications folder. No Homebrew formula, no npm package, no Docker image.
Where does it run?
In your menu bar. Pluk starts local servers on localhost — one per connected tool. It uses no resources when idle.
Which agents work with it?
Any coding agent that supports MCP endpoints: Claude Code, Cursor, Windsurf, Antigravity, and others. If the agent can take an MCP server URL, it works with Pluk.
What does it cost?
Nothing. Pluk is free software, released under the GNU Affero General Public License v3.0.
What about Windows and Linux?
macOS is first. Windows and Linux builds are coming next.

Ready to try it?

Download Pluk, connect a tool, and paste the URL into your agent. That is the whole setup.
